# SIPL Language for VS Code

Підтримка мови SIPL (курс «Теорія програмування», КНУ): розширення `.sipl`, підсвічування ключових слів, змінних, чисел і операторів, коментарі `//`, пари `begin/end` та дужок, автовідступи, сніпети `program`, `while`, `if`, `begin`, `assign`.

## Встановлення з `.vsix`

```bash
code --install-extension sipl-language-0.5.0.vsix
```

## Сумісність

VS Code 1.80+. Ядро мови (парсер, інтерпретатор, терми) — окремий Python-пакет `sipl-toolkit`; розширення не містить логіки мови.
