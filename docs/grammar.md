# Граматика SIPL

## БНФ курсу (практикум, с. 8)

```
P ::= begin S end
S ::= x := a | S1 ; S2 | if b then S1 else S2 | while b do S | begin S end | skip
a ::= n | x | a1 + a2 | a1 - a2 | a1 * a2 | (a)
b ::= a1 = a2 | a1 > a2 | b1 ∨ b2 | ¬ b | (b)
x ::= ... M | N | ...
n ::= ... -1 | 0 | 1 | 2 | ...
```

Ця БНФ неоднозначна: `1 + 2 * 3` та `S1; S2; S3` мають кілька дерев виводу. Машинна граматика `src/sipl/grammar/sipl.lark` породжує ту саму мову, але однозначно, завдяки стратифікації за пріоритетами.

## Відповідність правил

| Курс | Lark | Пояснення |
|---|---|---|
| `P` | `program` | `begin seq end` |
| `S1; S2` | `seq` | ліворекурсивне `seq ; stmt`, найнижчий пріоритет |
| `S` | `stmt` → `assign`, `if_stmt`, `while_stmt`, `block`, `skip_stmt` | гілки `if`/`while` — один оператор, тому `while` «сильніше» за `;` |
| `a` | `aexpr` → `term` → `factor` | `+ -` (рівень 1) < `* div mod` (рівень 2), ліва асоціативність |
| `b` | `bexpr` → `bterm` → `bfactor` | `or` < `and` < `not` |
| `x` | `var: NAME` | ключові слова виключені |
| `n` | `num: INT` | `-?[0-9]+` |

## Розширення (позначені як extension)

| Конструкція | Навіщо | Функція в термі |
|---|---|---|
| `div`, `mod` | варіанти практикуму 2, 4, 9, 15 | `div`, `mod` |
| `>=`, `<`, `<=`, `!=` (також `≥ ≤ ≠`) | зручність; `gre` використано в практикумі | `gre`, `ls`, `lse`, `neq` |
| `and` / `∧` | зручність | `and` |
| `true`, `false` | константні предикати | константи |
| `or`/`∨`, `not`/`¬` | ASCII-запис операцій курсу | `or`, `neg` |
| `–`, `−`, `×`, `∗` | вставка тексту з PDF | нормалізуються до `-`, `*` |
| `// коментар` | документування прикладів | — |

Програми, що не використовують розширень, розбираються точно за БНФ курсу.
